# Шаблон проекта для разработки лендинга с ИИ-агентами

Этот репозиторий — готовый каркас для создания лендинга с помощью цепочки ИИ-агентов.
Вся работа агентов фиксируется в унифицированных документах (json/md), чтобы можно было
откатиться на шаг назад, поправить артефакт и продолжить дальше.

## Быстрый старт
1. Положите все исходные материалы в `context/raw/` (презентации, заметки, ссылки, транскрипты).
2. Запустите агента-экстрактора с `roles/extractor.md`.
3. Дальше двигайтесь по шагам из `WORKFLOW.md`.

## Структура проекта
- `context/` — исходный контекст проекта (произвольные файлы)
- `guides/` — выжимка методологии и правил
- `templates/` — унифицированные шаблоны артефактов
- `artifacts/` — заполненные артефакты по проекту
- `roles/` — промпты и алгоритмы для каждой роли агента
- `landing/` — код лендинга (верстка)
