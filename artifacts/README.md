# Артефакты проекта

В этой папке хранятся результаты работы агентов. Все файлы имеют фиксированные шаблоны.
Если нужно изменить результат, правьте файл соответствующего шага и перезапускайте
следующие шаги.

Ключевые файлы:
- `artifacts/project_summary.md` — источник истины по смыслу проекта.
- `artifacts/iteration_notes.md` — замечания для новой итерации.
