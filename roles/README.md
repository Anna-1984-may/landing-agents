# Роли агентов

Каждый файл содержит готовый промпт и алгоритм работы роли.
Добавляйте нужный файл в контекст агента и запускайте задачу.

Список ролей:
- `roles/extractor.md` — извлечение и нормализация контекста
- `roles/strategist.md` — Jobs-карта и смысловые опоры
- `roles/positioning.md` — ценности, oneliner и CTA
- `roles/copywriter.md` — тексты блоков
- `roles/architect.md` — сценарий и структура лендинга
- `roles/visual.md` — визуальные контексты и промпты изображений
- `roles/image_generator.md` — генерация изображений из промптов
- `roles/ux.md` — wireframe
- `roles/frontend.md` — верстка
- `roles/qa.md` — проверка качества
- `roles/feedback.md` — ретроспектива процесса и рекомендации
