# Методология текстов и Jobs-логика

## Jobs-иерархия
- Super Big Job: жизненная цель.
- Big Job: конкретная жизненная задача.
- Core Job: ключевые работы, которые выполняет продукт.
- Micro Job: маленький шаг пользователя (CTA).

## Логика коммуникации
- Всегда идти от Big Job → Core Job → ценность → фичи.
- Не начинать с фич.

## Oneliner
Формула: что это + какую Core Job выполняет + с какой ценностью.
Требование: 60–80 символов, читается за ~6 секунд.

## Типовые формулы сообщений
1. Core Job + Big Job / Super Big Job
2. Core Job + ценность
3. Триггер + Core Job
4. Как выполнить Big Job (ориентационный контент)
5. Big Job / Core Job (прямое обещание результата)
6. Micro Job (подписка, уведомления)
7. Проблема текущего решения → наше решение Core Job

## Ценность без абстракций
Запрещены общие слова без расшифровки:
- быстро, удобно, безопасно, качественно, надежно, интуитивно

Правило: на каждую ценность ответь на вопрос «Это как?» и дай проверяемый результат.

## Контекстный визуал
- Изображение усиливает Job и показывает точку Б (ожидаемый результат).
- «Красивая картинка» без контекста ослабляет смысл.

## Что должен коммуницировать лендинг
1) Oneliner (что это)
2) Big Job + Core Jobs
3) Ценность
4) Контекст пользователя (триггеры, точка А)
5) Альтернативы хуже (активирующее знание)
6) Снятие барьеров (страхи, доверие)
