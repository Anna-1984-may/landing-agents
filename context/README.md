# Контекст проекта

Сюда складываются любые исходные материалы:
- презентации
- заметки
- расшифровки интервью/созвонов
- ссылки и бенчмарки
- существующие лендинги и тексты

Положите файлы в `context/raw/`. Агент-экстрактор сам извлечет информацию и заполнит
унифицированный бриф в `artifacts/brief.json`.
